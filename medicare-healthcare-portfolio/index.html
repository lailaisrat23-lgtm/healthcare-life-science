          How the demonstration works

          Four illustrative stages show the intended patient journey. Appointment requests are never transmitted and no real booking is created at any stage.

          1. Find a service

            Browse services, specialists, clinics, tests and catalogue entries.

          2. Explore details

            Open a record to see the full fictional profile or specification.

          3. Request an appointment

            Complete the static request form. It validates locally and stops there.

          4. Review demo status

            Look up a sample reference ID to inspect simulated status labels.

          No request leaves your browser

          Form submissions are handled entirely in the page. Nothing is stored, and no clinic, laboratory, pharmacy or supplier is contacted.
